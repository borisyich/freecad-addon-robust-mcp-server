# FreeCAD engineering-agent router

For tasks that create, reconstruct, modify, repair, validate, or document a
mechanical model in FreeCAD, activate `$freecad-engineering` and follow
`.agents/skills/freecad-engineering/SKILL.md`.

If the client cannot load repository Skills, read
`freecad://skills/freecad-engineering`. Load only the reference files selected
by that router. Do not duplicate engineering workflow policy in `AGENTS.md`.
